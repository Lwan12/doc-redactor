# 回头路径计划

依据：`back-path-flow.md` 的回退表和第 3 节；界面位置与文案以晚于该文件的 `brief.md` 第 20 条、`方案.md` 2.9 和 `prototype.html` 为准。命令行输出约定不改。

## 逻辑（无 tk，`backpath.py`）

- 签名 = 文件列表路径 + 已勾规则的内容（名字、类型、匹配写法、占位符、词、例子、大小写）。签名没变才把取消勾选套回新扫描；变了就全部按命中，并给出说明。
- 回头清掉本次扫描结果和预览。文件、规则勾选、改过的占位符、输出文件夹、规则编辑页已输入的例子和测试文字都留着。已写出的文件不删不改。
- 重扫前没有新的扫描结果，「写出」不可用。
- 每次写出在输出文件夹下新建 `YYYYMMDD-HHMM`（同一分钟已存在则 `-2`、`-3`）。同名文件默认另存加序号，覆盖要主动选。目标路径不得等于原文件。
- 某个文件写出失败只记在该文件上，已写出的留下。重试只写失败的那些。
- 步骤条点击和「返回修改 / 返回选文件」共用 `decide_leave`。关窗口只用 `decide_close`：结果页、还没写出、还有预览，三条同时成立才提示。
- 取消扫描丢弃已扫结果，不写出一半。

## 界面

- 主界面拆成选文件页、选规则页。两个页面 Frame 只建一次，切换用 `tkraise()`，不销毁。
- 步骤条每个步一个 `tk.Label`。走过且在当前步之前的：下划线、`<Button-1>`、悬停小提示。当前步、没走到的、扫描中：不绑定点击。
- 文案逐字用方案 2.9；方案没写满的第二句以原型为准（规则改过且曾取消勾选时，选规则页写「原来取消勾选的位置会清除」）。
- 确认用现有自绘对话框，不用 `messagebox`。界面不出现「正则」。
