# 桌面界面改造计划（feat/ui）

依据：内部界面方案稿（brief、方案、规则输入流程、原型）。Lee 已拍板项不再重开。

## 功能清单

1. **一个窗口、三个画面**：主界面 / 结果页 / 规则设置。弹窗仅用于同名文件、关闭未写出、导出。`root.minsize(960, 640)`。
2. **主界面**：拖入或「选择文件… / 选择文件夹…」；文件表（文件名/类型/大小/状态）；右侧规则勾选；输出目录；「开始扫描」。空态、已添加、输出夹出错、处理中（右栏变灰）、已取消（⊘）。
3. **结果页（先扫后写）**：顶部总数；提示条「原文只在这个窗口里临时显示…」；「隐藏原文，只看位置」；三栏文件 / 预览 / 类别+位置。取消勾选一处，顶部总数、文件替换数、类别个数、位置清单、主按钮数字五处同时变，并出现「（你取消了 N 处）」。Word 默认 `[REDACTED:类别]`；PDF/图片涂黑；PDF 写出用 `apply_redactions` 真删文字。命中清单只写类别和次数。
4. **规则**：列表（启用/名/类型/例子/修改删除，无适用范围）；新增（贴例子→猜白话→测试框高亮）；照样写（`#` 数字、`@` 字母）；模板；高级折叠（匹配写法，界面不出现「正则」）；9 种提示语逐字照抄；删除 10 分钟内可撤销（仅内存）；顶部一次撤销。
5. **词表页**：名、区分大小写（默认不勾）、加词、导入文本、多选删除、撤销上一步、重复词就地提示、空表确定灰着。
6. **常用规则库 7 条**：项目号、方案号清单（词表，空清单无命中）、申办方、药名、NCT 试验登记号默认勾；邮箱、手机号不勾。「字母加数字」是方案号清单的备选子项（不占条数），默认不勾，清单没勾时不可勾，提示「这条抓不全，也可能误伤」。
7. **导入/导出**：预览（＋新增 N / ⚠重名 M / ✕无效 K）；重名默认跳过，可改名/覆盖；旧 yaml 保留原 `case_sensitive`。导出不含测试文字和原文。
8. **命中过多只提醒**：测试框 >20 处、单文件 >500 处。界面只写实际数 N，不写阈值。不拦截确定/写出。
9. **拖拽**：能 import `tkinterdnd2` 就用；打进 PyInstaller 包（`collect_all`）；失败则只留「选择文件…」，界面和 README 说明。
10. **确认**：自绘 `Toplevel`，不用 `messagebox`。取消扫描不确认。

## 边界 / 不做

- 项目范围/适用范围、受试者编号、身份证、日期预设。
- 界面出现「正则」「表达式」「pattern」字样；圆角/渐变/阴影/动画/`messagebox` 确认。
- 原文或命中位置写入任何文件；联网；改 CLI 输出约定（仍是 `<stem>.redacted.<ext>` + `report.json`）。
- PDF 页面图版预览、左右对照预览、NER/人名、`.doc/.xlsx/.pptx`。
- 持久化规则到系统目录（导入导出即可；进程内保留）。撤销超过 10 分钟或进程退出即失效。

## 实现拆分

业务逻辑与界面分开，核心模块无 tk 依赖，便于单测。

| 模块 | 职责 |
|---|---|
| `src/doc_redactor/pattern_guess.py` | 例子/照样写/模板 → 白话描述 + 内部写法；测试框命中；9 种提示语常量；阈值 20。 |
| `src/doc_redactor/ruleset.py` | 规则/词表增删改、启用、10 分钟撤销、常用库、导入预览与执行、导出、旧 yaml 大小写保留、词表重复词。 |
| `src/doc_redactor/scan.py` | 先扫描得命中位置（内存），再按勾选写出；单文件阈值 500；报告只含类别次数。 |
| `src/doc_redactor/gui/` | 主题、对话框、主/结果/规则画面、测试钩子。入口仍是 `doc_redactor.gui:main`。 |
| `config.py` | 词表节点可写 `terms` 内联（导出用）；`path` 仍可用。 |
| `docx_redactor.py` / `pdf_redactor.py` / `image_redactor.py` | 增加扫描/按命中写出；PDF 仍 `apply_redactions`；图片涂黑；Word 替换。CLI 原路径不改。 |
| `doc-redactor.spec` | `collect_all("tkinterdnd2")`，失败则跳过。 |
| `tools/shoot_gui.py` | xvfb 无头驱动各态，截 960×640 到 `deliverables/doc-redactor-ui/real-screenshots/`。 |
| `tests/test_ruleset.py` 等 | 规则新增/导入跳过/旧 yaml 大小写/撤销 10 分钟/常用库/照样写/阈值 20·21 与 500·501/词表重复/取消勾选后写出数。 |
| `README.md` | 中文界面说明、拖拽降级、已知限制。 |

## 界面约定（已定）

- 主题 `ttk` `clam`；字体微软雅黑 11pt（Linux 回退 Noto Sans CJK SC），数字/文件名/路径 Consolas。
- 色：底 `#fafafb`，面板 `#ffffff`，标题 `#f7f8f9`，表头 `#f1f2f3`，线 `#ecedef`，主字 `#1f2124`，次字 `#62656b`，选中 `#e7e9eb`，主按钮 `#0070dd`，成功 `#008035`，失败 `#cb2f39`，取消/警告 `#c04700`；命中 `#fff3b0`，当前 `#ffd84d`。直角。
- 状态 = 图标 + 文字 + 颜色：○ 待处理、◔ 处理中、✓ 已扫描/有命中/已写出、— 无命中、✕ 失败、⊘ 已取消、⚠ 提醒。
- 类别 ①②③；高亮底色统一。
- 间距 4/8/12/16；Treeview `rowheight` 26–28。

## 自检

对 `samples/` 三个文件 + 另造一份含内嵌图的 docx，无头调用 `scan.py` 写出。PDF 抽文本、Word 全 xml、图片再 OCR，确认原词不在；`report.json` 无原文。
